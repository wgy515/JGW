应用程序向导已为您创建了此 CTSEMultipleTestPlugin DLL。

本文件概要介绍组成 CTSEMultipleTestPlugin 应用程序的每个文件的内容。


CTSEMultipleTestPlugin.vcxproj
    这是使用应用程序向导生成的 VC++ 项目的主项目文件，
    其中包含生成该文件的 Visual C++ 
    的版本信息，以及有关使用应用程序向导选择的平台、配置和项目功能的信息。

CTSEMultipleTestPlugin.vcxproj.filters
    这是使用“应用程序向导”生成的 VC++ 项目筛选器文件。 
    它包含有关项目文件与筛选器之间的关联信息。 在 IDE 
    中，通过这种关联，在特定节点下以分组形式显示具有相似扩展名的文件。
    例如，“.cpp”文件与“源文件”筛选器关联。

CTSEMultipleTestPlugin.cpp
    这是主 DLL 源文件。

	此 DLL 在创建时不导出任何符号。 因此，在生成此 DLL 时
 	生成时不会产生 .lib 文件。 如果希望此项目
 	成为其他某个项目的项目依赖项，则需要
 	添加代码以从 DLL 导出某些符号，
 	以便产生一个导出库，或者，也可以在项目“属性页”对话框中的
 	“链接器”文件夹中，将“常规”属性页上的
 	“忽略输入库”属性设置为“是”。

一、自动识别（网卡插入连接状态更新）
1、JGW_ReportDeviceInfo 上报物理断开和物理连接改变信息
2、读取到物理连接信息（当前线程不处于E_TSEMP_BUSY），更改UI锁定状态改为E_TSEMP_INST状态
3、读取到物理断开信息（当前线程不处于E_TSEMP_BUSY），更改UI锁定状态改为E_TSEMP_IDLE状态
4、当前UI锁定状态为E_TSEMP_INST，检查PING网络连接状态能够ping通，将当前线程改为E_TSEMP_BUSY状态，并且将Progress Pos设置为0
5、当前UI锁定状态持续为E_TSEMP_BUSY时，Progress Pos不断自加，并且不断更新UI相关信息
6、当前UI锁定状态E_TSEMP_FAIL时，显示颜色改为红色，并且记录当前物理连接状态，当物理连接状态更改时将状态TEXTUI改为指定物理连接信息
7、当前UI锁定状态E_TSEMP_PASS时，显示颜色改为红色，并且记录当前物理连接状态，当物理连接状态更改时将状态TEXTUI改为指定物理连接信息
